## Project facts verified from source
- Product scope: press production entry/reporting plus an operator production module.
- Runtime: Node.js `>=22.13`; package scripts are `start` and `dev`.
- Backend: Node built-in HTTP server, custom router, built-in `node:sqlite`; no npm dependencies declared.
- Frontend: plain HTML, CSS and browser JavaScript split into core, report and view files.
- Database: SQLite file at `data/datacenter.db` by default; `DATA_DIR` can relocate it.
- Default port: `3000`; configurable with `PORT`.
- Backups: SQLite `VACUUM INTO`; automatic backup retention defaults to 14.
- The supplied ZIP contains source and assets, but no `data/` runtime database directory.
